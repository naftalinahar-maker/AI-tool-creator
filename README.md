# 🎬 AI Movie Studio

אפליקציית Next.js שיוצרת סרטים קצרים בעזרת בינה מלאכותית: כותבים רעיון לעלילה,
והאפליקציה בונה תסריט מחולק לסצנות, מנגנת אותו כסרט מונפש עם קריינות קולית
ופס קול נוצר-אלגוריתמית, ומאפשרת להוריד את התוצאה כקובץ וידאו.

## איך זה עובד

1. **תסריט** — טופס קלט (כותרת, ז'אנר, אווירה, רעיון עלילה, מספר סצנות) שולח
   בקשה ל-`/api/generate-script`.
   - אם מוגדר `ANTHROPIC_API_KEY`, השרת קורא ל-Claude (`lib/anthropicScript.ts`)
     כדי לכתוב תסריט מובנה (JSON) עם קריינות, כיתובים ותיאורים חזותיים לכל סצנה.
   - ללא מפתח, נכנס לפעולה מחולל טקסט מובנה שפועל לגמרי לא מקוון
     (`lib/scriptGenerator.ts`) עם מאגרי מילים בעברית לפי ז'אנר, כך שהאפליקציה
     עובדת מהקופסה גם בלי שום מפתח API.
2. **סטוריבורד** — כל הסצנות מוצגות ככרטיסים ניתנים לעריכה (`components/Storyboard.tsx`,
   `SceneCard.tsx`) לפני שממשיכים להפקה.
3. **נגן הסרט** — `components/MoviePlayer.tsx` מצייר כל סצנה על `<canvas>` עם
   אפקט Ken Burns, כותרות וכיתובים, מקריא את הקריינות בעזרת Web Speech API
   (`hooks/useSpeechSynthesis.ts`), ומנגן פס קול נוצר-אלגוריתמית לפי מצב הרוח
   של הסצנה באמצעות Web Audio API (`hooks/useProceduralScore.ts`).
4. **ייצוא** — לחיצה על "ייצוא הסרט" מקליטה בזמן אמת את זרם ה-canvas ואת פס
   הקול (`canvas.captureStream` + `MediaRecorder`) לקובץ `.webm` להורדה. אפשר
   גם להוריד את התסריט כקובץ טקסט.

כל זה פועל כולו בצד הלקוח (חוץ מיצירת התסריט עם Claude, שדורשת שרת), בלי
תלות בשירותי תמונה/וידאו/קול בתשלום.

## הרצה מקומית

```bash
npm install
npm run dev
```

פתחו את [http://localhost:3000](http://localhost:3000).

### הפעלת יצירת תסריטים עם Claude (אופציונלי)

```bash
cp .env.example .env.local
# הוסיפו בקובץ:
# ANTHROPIC_API_KEY=sk-ant-...
```

ללא מפתח, האפליקציה ממשיכה לעבוד במלואה עם המחולל הלא-מקוון.

## מבנה הפרויקט

```
app/
  page.tsx                  עמוד ראשי: טופס → סטוריבורד → נגן
  api/generate-script/      נקודת קצה ליצירת תסריט
lib/
  types.ts                  טיפוסים: Movie, Scene, Genre, Mood
  mood.ts                   מיפוי מצב-רוח → צבעים וסולם מוזיקלי
  scriptGenerator.ts        מחולל תסריטים לא-מקוון (עברית)
  anthropicScript.ts        מחולל תסריטים מבוסס Claude
  canvasArt.ts              צורות דקורטיביות דטרמיניסטיות לכל סצנה
components/
  MovieForm.tsx             טופס קלט
  Storyboard.tsx / SceneCard.tsx   עריכת הסטוריבורד
  MoviePlayer.tsx            נגן ה-canvas, קריינות, מוזיקה וייצוא
hooks/
  useSpeechSynthesis.ts     עטיפת Web Speech API
  useProceduralScore.ts     מחולל מוזיקה עם Web Audio API
```

## מגבלות ידועות

- הורדת הסרט (`.webm`) כוללת ויזואלים, כיתובים ומוזיקה, אך **לא** את הקריינות
  הקולית — דפדפנים לא מאפשרים כרגע להקליט את פלט ה-Web Speech API לקובץ.
  בצפייה חיה באפליקציה הקריינות כן מתנגנת.
- ייצוא הסרט מתבצע בזמן אמת (אורך ההקלטה שווה לאורך הסרט), ודורש להשאיר את
  הטאב פתוח וגלוי עד לסיום.
