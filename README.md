# 🎬 AI Movie Studio

אפליקציית Next.js שיוצרת סרטים קצרים בעזרת בינה מלאכותית: כותבים רעיון לעלילה,
והאפליקציה בונה תסריט מחולק לסצנות, מנגנת אותו כסרט מונפש עם קריינות קולית
ופס קול נוצר-אלגוריתמית, ומאפשרת להוריד את התוצאה כקובץ וידאו.

## איך זה עובד

1. **💡 מחולל רעיונות AI** — כפתור בטופס שממציא שם, ז'אנר, אווירה ועלילה.
2. **תסריט** — סצנות קצרות (4–10 שניות כל אחת), עם קריינות, כיתוב ופרומפט וידאו באנגלית.
3. **ויזואלים AI לכל סצנה** — דרך "מנוע הסרטים" (`lib/videoEngine.ts`), ממשק אחד
   מעל כמה ספקים. הוא מנסה קודם את הספק החינמי, ועובר לספק הבא אם ספק נכשל.
4. **נגן** — מצייר את התמונה/הווידאו של כל סצנה על `<canvas>` עם כיתובים,
   קריינות קולית ופס קול נוצר-אלגוריתמית, ומייצא הכול לקובץ `.webm`.

### מה עולה כסף ומה לא

| יכולת | חינם | בתשלום (אופציונלי) |
|---|---|---|
| רעיונות ותסריט | מחולל מובנה; או Claude מהחשבון שלך כשפותחים את האפליקציה כקישור ב-claude.ai | `ANTHROPIC_API_KEY` (Claude בשרת) |
| ויזואלים | **Pollinations.ai** – תמונת AI לכל סצנה, בלי מפתח, והנגן מנפיש אותה | — |
| וידאו AI אמיתי (4–10 שניות) | — | Google Veo (`GEMINI_API_KEY`), fal.ai (`FAL_KEY`), Replicate (`REPLICATE_API_TOKEN`), Runway (`RUNWAYML_API_SECRET`) |
| קריינות, מוזיקה, ייצוא | הכול בדפדפן | — |

הספקים בתשלום נכתבו בלי גישה לתיעוד העדכני שלהם. לפני שימוש כדאי לוודא את
מזהי המודלים, ואפשר לשנות אותם דרך משתני הסביבה ב-`.env.example`.
ספק שהבקשה נקבעה לו משך שהוא לא תומך בו מקבל את המשך הקרוב שהוא כן תומך בו,
והנגן חותך את הקליפ לאורך הסצנה.

## הרצה מקומית

```bash
npm install
npm run dev
```

פתחו את [http://localhost:3000](http://localhost:3000).

### מפתחות (כולם אופציונליים)

```bash
cp .env.example .env.local
```

בלי אף מפתח האפליקציה עובדת בחינם: מחולל מובנה לטקסט ותמונות AI מ-Pollinations.

## מבנה הפרויקט

```
app/
  page.tsx                  עמוד ראשי: טופס → סטוריבורד → נגן
  api/generate-script/      יצירת תסריט
  api/generate-idea/        יצירת רעיון
  api/media/*               מנוע המדיה: providers / start / status / file
lib/
  types.ts                  טיפוסים: Movie, Scene, Genre, Mood
  mood.ts                   מיפוי מצב-רוח → צבעים וסולם מוזיקלי
  scriptGenerator.ts        מחולל תסריטים לא-מקוון (עברית)
  anthropicScript.ts        תסריטים ורעיונות עם Claude (שרת)
  prompts.ts                פרומפטים וסכמות JSON משותפים
  ideaGenerator.ts          מחולל רעיונות לא-מקוון
  videoEngine.ts            מנוע מדיה מאוחד (Pollinations, Veo, fal, Replicate, Runway)
  aiClient.ts               שרשראות הגיבוי בצד הלקוח
  canvasArt.ts              צורות דקורטיביות דטרמיניסטיות לכל סצנה
components/
  MovieForm.tsx             טופס קלט
  Storyboard.tsx / SceneCard.tsx   עריכת הסטוריבורד
  MoviePlayer.tsx            נגן ה-canvas, קריינות, מוזיקה וייצוא
hooks/
  useSpeechSynthesis.ts     עטיפת Web Speech API
  useProceduralScore.ts     מחולל מוזיקה עם Web Audio API
```

## מגבלות ידועות

- הורדת הסרט (`.webm`) כוללת ויזואלים, כיתובים ומוזיקה, אך **לא** את הקריינות
  הקולית — דפדפנים לא מאפשרים כרגע להקליט את פלט ה-Web Speech API לקובץ.
  בצפייה חיה באפליקציה הקריינות כן מתנגנת.
- ייצוא הסרט מתבצע בזמן אמת (אורך ההקלטה שווה לאורך הסרט), ודורש להשאיר את
  הטאב פתוח וגלוי עד לסיום.
