# תיק לקוח

נפתלי פומברג ("לשווק בכיף עם נפתלי") מלווה בעלי עסקים: מאמנים, מטפלים, רבנים, מורים ויזמים שרוצים להפיץ את המסר שלהם בלי לוותר על הערכים שלהם. כל לקוח מקבל תיקייה אחת, וכל העבודה עליו נשענת עליה.

**הכלל:** מה שלא בתיקייה, לא קיים. בתחילת כל עבודה על לקוח קוראים קודם את התיקייה שלו.

## מבנה התיקייה

```
לקוחות/<שם-הלקוח>/
  client.md      מי הלקוח, מה הוא מוכר, למי, מסלול הליווי, שלב נוכחי, אחראי בצוות
  brand.md       צבעים (קודי צבע), לוגו, פונטים, טון דיבור, מילים שהוא אוהב ושלא
  plan.md        תוכנית עבודה לפי שבועות
  tasks.md       משימות פתוחות וסגורות
  calls/         תמלולי פגישות, קובץ לכל פגישה: YYYY-MM-DD.md
  funnels/       קבצי משפך (נוצרים בסקיל naftali-funnel-builder)
  pages/         דפי נחיתה
  reports/       דוחות קמפיין
  assets/        לוגו, תמונות, המלצות שהלקוח שלח
```

## פעולה 1: לקוח חדש
1. שואלים את נפתלי, שאלה אחר שאלה ולא הכל בבת אחת:
   - שם העסק ומה הוא מוכר (מוצר, מחיר, למי)
   - מסלול הליווי: תוכנית "לשווק בכיף" (עשרה שבועות), ליווי אישי, או שיווק מלא
   - הכנסה חודשית היום ויעד
   - מי בצוות אחראי
   - קישורים: אתר, פייסבוק, אינסטגרם
   - ערכים או קווים אדומים בשיווק (למשל צניעות בתמונות, שפה)
2. יוצרים את התיקייה והקבצים. client.md מתחיל בשורות הקבועות האלה (מסך הניהול קורא אותן):
   ```
   שלב: אבחון | אסטרטגיה | בנייה | קמפיין פעיל | אופטימיזציה | הסתיים
   מסלול: <המסלול>
   אחראי: <שם>
   עדכון אחרון: YYYY-MM-DD
   ```
3. אם יש אתר, קוראים אותו וממלאים מתוכו את brand.md (צבעים, טון). מה שלא ברור, מסמנים "לברר".
4. בונים טיוטת plan.md לפי המסלול, ומציגים לנפתלי לאישור.

## פעולה 2: אחרי פגישה
כשנפתלי מעלה תמלול (מזום, גוגל מיט או הקלטה):
1. שומרים אותו ב־calls/ עם תאריך.
2. מוציאים: מה הוחלט, מה הלקוח צריך לשלוח, מה הצוות צריך לעשות, חששות או התנגדויות.
3. מעדכנים את plan.md ואת tasks.md, ואת "עדכון אחרון" ב־client.md.
4. מנסחים הודעת סיכום ללקוח לוואטסאפ: חמה, קצרה, בגוף ראשון של נפתלי, עם רשימת "מה עליך עד הפגישה הבאה".
5. מסיימים בשורה אחת: מה הצעד הבא החשוב ביותר.

## פורמט tasks.md
שורה לכל משימה, בדיוק בתבנית הזו (מסך הניהול קורא אותה):
```
- [ ] טקסט המשימה | אחראי: <שם> | עד: YYYY-MM-DD | שלב: <שלב>
- [x] משימה שהושלמה | אחראי: <שם> | עד: YYYY-MM-DD | שלב: <שלב>
```
